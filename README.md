# ATU Software Development: Control Flow

Eight C# exercises from Gerard McCloskey’s first Control Flow worksheet. Each folder is a separate .NET 10 console project with its own `Program.cs`.

## Run in GitHub Codespaces

Open the repository in Codespaces. In its terminal, run for example:

```bash
dotnet run --project 01-Marital-Status
```

Replace the folder name with any exercise below. If `dotnet` is not installed in the Codespace, install the official .NET 10 SDK or use a Codespaces image with .NET.

## Exercises

- **01-Marital-Status**: Use a switch statement to display the marital status for S, M, W, E or D; show an error for another character.
- **02-Divisibility**: Read two integers and check whether the first is evenly divisible by the second using %.
- **03-Minimum**: Read two integers and find the minimum using the ternary operator.
- **04-Time-Zones**: Read an Irish time in 24-hour HH.MM format and show Washington (-5 h), Moscow (+3 h) and Tokyo (+9 h). Use the fixed offsets specified in the sheet.
- **05-Odd-Sum**: Use a for loop to sum the odd numbers from 1 to 99.
- **06-Even-Sum**: Use a while loop to sum the even numbers from 100 to 199.
- **07-Squares-Cubes**: Display a table of squares and cubes for numbers 1 through 5.
- **08-Triangle**: Read three side lengths; a valid triangle has positive sides and each pair sums to more than the remaining side.
